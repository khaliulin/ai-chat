# CDEK AI Assistant - Список фичей и улучшений

Данный документ содержит описание реализованных функций и дизайнерских решений в прототипе ИИ-помощника СДЭК.


## 💬 Интерфейс чата и UX
- **Четыре режима отображения:**
  - **Full Page:** Полноэкранный режим лендинга.
  - **Sidebar:** Боковая панель-переключатель (Drawer), которая не перекрывает контент, а сдвигает или накладывается справа.
  - **Float:** Минимизированный плавающий вид с кнопкой вызова.
  - **Embedded:** Встроенный блок в структуру страницы.
- **Навигация и контроль:** Кнопки изменения формата (Развернуть/Свернуть/Минимизировать) и быстрый сброс на «Новый чат».
- **Контекстное меню беседы:** Кнопка «...» для каждого чата, позволяющая быстро добавить в избранное, переименовать или удалить беседу.
- **Управление историей:** Полноценная боковая панель с группировкой диалогов по датам, поиском по истории и отдельным блоком для **запиненных (Pinned)** бесед.

## 🛒 Функциональные возможности
- **Экшен-карточки возможностей:** Сетка из 6 интерактивных блоков на стартовом экране для быстрого доступа к ключевым сервисам (Отслеживание, Шоппинг, Расчет, API CDEK, CDEK Wiki).
- **Голосовой ввод:** Интерактивный режим записи с визуализацией звуковой волны (Waveform) и возможностью прослушивания аудиоответов.
- **Автодополнение (Autocomplete):** Подсказки при наборе текста, помогающие быстрее сформулировать популярные запросы.
- **Мультимедиа и вложения:** Поддержка прикрепления файлов и визуализация различных типов контента (картинки, списки, источники информации).
- **CDEK Wiki и PDF-отчеты:** Возможность генерации аналитических отчетов на основе внешних данных (CDEK Wiki) с последующей визуализацией файла и возможностью его скачивания в формате PDF прямо из чата.
- **Интеграции (CDEK Shopping):** Полноценный GUI-модуль внутри чата с карточками товаров, ценами, рейтингами и процессом оформления заказа.
- **Инструменты управления ответом:** Панель быстрых действий под ответом ИИ (Развернуть мысль, Короче, Больше контекста) для мгновенной корректировки результата.
- **Обратная связь:** Возможность оценки ответов ИИ (лайк/дизлайк) и быстрые действия с сообщением (копирование, шеринг).
- **Умные подсказки (Follow-up):** После каждого ответа ИИ предлагает логичные варианты продолжения диалога в виде кнопок-баблов (например, «Изменить адрес», «Связаться с курьером»).
